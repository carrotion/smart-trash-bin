# 진행 정리 및 다음 작업 (2026-08-20)

## 1. 오늘 한 일

시작은 사용자 관찰 **"모터별 반응속도가 달라서 출발할 때 방향이 틀어진다"** 였다.
측정해보니 반응속도 차이가 아니라 **채널 하나가 죽어 있었고**, 거기서 실이 풀렸다.

| 순서 | 발견 / 조치 | 결과 |
|---|---|---|
| 1 | 기동 시험 8회 평균 | **M4(오른쪽 앞) 구동 사망** — 1.2초 내내 카운트 0 |
| 2 | 사용자가 커넥터 재체결 | 4채널 복구 |
| 3 | 채널별 개별 구동 4회 반복 | **M3(오른쪽 뒤)만 22% 부족**, 재현됨 |
| 4 | **PWM 스윕 (200/300/450/600)** | **절대 부족량 일정(약 1000)** → 기계적 드래그 확정 |
| 5 | 채널별 PWM **오프셋** 보정 적용 | 좌우 불균형 8.1% → **1.4%** |
| 6 | 바닥 직진 측정 | 이탈각 −13° → **−5.7°** |
| 7 | 사용자가 우측 바퀴 정렬 조정 | **−2.2°** (표준편차 0.9° → 0.2°) |
| 8 | 한 번 더 조정 | **+3.5°** — 부호 전환, 최적점이 그 사이로 확정 |

### 핵심이 된 측정: PWM 스윕

세 가설이 **전류에 따라 서로 다른 흔적**을 남긴다는 점을 이용했다.

    PWM        200    300    450    600
    M3 부족(절대)  1005   1006   1031    969   <- 일정
    M3 부족(비율) 25.6%  23.2%  20.8%  17.5%  <- 감소

| 가설 | 예상 | 실제 |
|---|---|---|
| 접촉 저항 (I×R) | 전류 커질수록 부족분 **증가** | ❌ |
| 약한 모터 (낮은 Kv) | **비율**이 일정 | ❌ |
| **기계적 드래그** | **절대량**이 일정 | ✅ |

이 측정은 사용자가 **"전체 파워 부족일 수도 있지 않냐"** 고 물어서 하게 됐다.
그 가설도 함께 배제됐다(PWM 600에서 다른 3채널이 정상 증가).

사용자의 독립 관찰 **"M3만 관성이 부족한 것처럼 빨리 멈춘다"** 와도 일치한다 —
같은 마찰이 구동 중엔 속도를 깎고 전원을 끊으면 더 빨리 세운다.

### 보정 방식이 데이터로 결정됐다

**절대 부족량이 일정** → 곱셈(gain)이 아니라 **덧셈(PWM 오프셋)**.
비율로 곱하면 저속에선 모자라고 고속에선 과해진다.
`motor_pwm_offset_m1..m4 = 75 / 0 / 240 / 0`

## 3. 내일 할 일

### 우선순위 1 — M3 드래그 원인 찾기 (5분)

**왜 먼저인가**: 유일하게 **소프트웨어로 못 잡는** 항목이다. 오프셋으로 구동 중은
보정했지만 감속은 마찰이 지배해서 개입할 수단이 없다.

1. 도크 위에서 **네 바퀴를 손으로 하나씩 돌려본다.** M3만 뻑뻑하면 확정
2. 돌리면서 **케이블이 타이어나 축에 닿는지** 눈으로 확인
3. **오른쪽 뒷바퀴 근접 사진**을 `docs/photos/`에 저장

원인 후보: 케이블 쓸림(커넥터 작업 직후 4382→3335로 변한 것과 부합) /
바퀴가 프레임에 스침 / 베어링·기어박스 뻑뻑함

### 우선순위 2 — 정렬 마무리 (10분)

마지막 조정의 **약 60%를 되돌린 뒤** `tools/straight_check.py --trials 3` 측정.

- **±1° 안쪽** → 완료. 0.5m에 0.5cm라 더 만질 실익 없음
- **부호가 또 뒤집히면** → 조정량을 절반으로 줄여 접근
- 후진값도 함께 볼 것 (지금 −9.7°). 토 정렬이 원인이면 전진을 0에 맞춰도
  후진에는 오차가 남는다 — Nav2 복구 동작(BackUp)에 영향

### 우선순위 3 — INA219 장착

납땜(6핀 헤더 + 나사 단자) → IMU 남는 Qwiic 포트에 데이지체인 →
`i2cdetect -y 1`에 **0x40** 확인 → 읽는 노드 작성 → 대시보드 그래프.

배선 상세는 `docs/hardware_inventory.md` 참고.
⚠️ **션트를 메인 라인에 직렬로 넣지 말 것** (0.1Ω × 15A = 22W, 저항이 탄다).

**이게 되면 앞으로 모든 측정에 전압이 함께 기록된다** — 08-17 회전 측정에
전압이 없어서 "13.6%인가 300%인가"를 끝내 못 가린 문제가 사라진다.

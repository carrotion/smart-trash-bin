## 1. 🔍 4WD 스키드-스티어(SSMR) 슬립 및 오차 역학 분석 (Kinematics & Dynamics)

### 1.1 기구학적 특성과 ICR (Instantaneous Center of Rotation) 이동
일반적인 2륜 차동구동(Differential Drive)은 회전 중심이 두 바퀴를 잇는 차축 선상에 완벽히 일치합니다.
반면, **고정축 4륜 스키드-스티어(4WD SSMR)**는 조향 장치(Steering Knuckle)가 없으므로 회전 시 **4개의 바퀴가 바닥면을 강제로 횡방향(Lateral)으로 긁으며 미끄러져야만(Scrubbing)** 합니다. *(Mandow et al., IEEE IROS 2007; Kozłowski & Pazderski, AMCS 2004)*

```
                  [ 전면 ]
     [M2: 전좌륜] -------- [M4: 전우륜]  ▲ Y (진행방향)
          |                    |        |
          |       (CoG)        |        +----> X (횡방향)
          |                    |
     [M1: 후좌륜] -------- [M3: 후우륜]
                  [ 후면 ]
     |<--------- W ---------->| (물리 윤거 트레드 폭: 0.17m)
     |<--------- L ---------->| (축거 휠베이스: ~0.15m)
```

* **횡마찰 저항 모멘트 ($M_{scrub}$)**:
  $$M_{scrub} = \sum_{i=1}^4 \mu_{y,i} \cdot F_{N,i} \cdot \sqrt{x_i^2 + y_i^2}$$
  (여기서 $\mu_{y,i}$는 횡방향 마찰계수, $F_{N,i}$는 바퀴당 수직하중)
* **실효 트레드($W_{eff}$) 팽창 현상**:
  - 고무 타이어와 마루 바닥 사이의 횡마찰계수($\mu_y \approx 0.8 \sim 1.0$)가 매우 커서, 모터가 바퀴를 돌려도 실제 로봇의 회전각속도는 기하학적 예측치보다 절반 가까이 떨어집니다.
  - 우리 로봇에서 실측된 물리 윤거(0.17m) 대비 **실효 윤거(0.329m, 1.94배)**가 나타난 원인이 바로 이 횡슬립 저항 모멘트 $M_{scrub}$ 때문입니다.
  - 이로 인해 **PWM 230 이하의 저속 회전 영역에서는 정지마찰 문턱을 넘지 못해 모터가 스톨(Stall)**되는 현상이 발생합니다.

### 1.2 종방향 슬립(Longitudinal Slip) 및 관성 쏠림
* **마찰 원뿔(Friction Cone) 이탈**:
  - 현재 `diff_drive_node`는 `cmd_vel` 명령이 들어오면 가감속 램프 없이 즉시 목표 PWM을 인가합니다 ($\Delta v / \Delta t \to \infty$).
  - 요구 구동력 $F = m \cdot a$가 정지마찰 한계 $F_{max} = \mu_s F_N$을 초과하는 순간 바퀴가 공회전(Wheel Spin)하며 주행 거리 오차($\Delta x$)가 적분됩니다.
* **정지 시 반동 편향 (Inertia Recoil)**:
  - 주행 중 모터에 갑자기 0V(정지)를 가하면, 쓰레기통 상부 및 배터리의 관성 모멘트에 의해 차체가 비틀리며 원래의 기계적 편향 위치로 되돌아가는 잔류 회전 오차가 발생합니다.

* **기각 사유**: 옴니휠은 외주면의 다수 롤러 사이 틈새로 인해 주행 시 지속적인 진동(Bumping), '달가닥'거리는 층간소음, 그리고 단단한 플라스틱 롤러로 인한 **가정용 마루 바닥 긁힘(Scratch)** 위험이 큽니다.

### 🥇 [방안 A+] 축간거리(Wheelbase, $L$) 축소 설계 — ★ 가장 정석적이고 우아한 기구학적 해법

**사용자께서 제기하신 "축간거리 축소"는 전후진 접지력은 100% 보존하면서 회전 저항만 선형적으로 격감시키는 스키드-스티어의 최적 설계 원리입니다.**

```
                  [ 전면 ]
     [M2] ---------------------- [M4]
      |                            |
      |             ▲              |
      |             | L (축간 거리) |   회전 중심에서 바퀴까지의
      |             ▼              |   종방향 모멘트 암 = L / 2
      |                            |
     [M1] ---------------------- [M3]
      |<------------ W ----------->| (윤거, 좌우 폭)
```

#### 📐 수학적 역학 증명
1. **회전 횡마찰 저항 모멘트 ($M_{scrub}$)**:
   $$M_{scrub} = \mu_y \cdot (mg) \cdot \frac{\mathbf{L}}{2}$$
   * 회전 시 바퀴가 횡방향으로 미끄러질 때 받는 저항 토크는 **축간거리($L$)에 정비례($M_{scrub} \propto L$)**합니다.
   * **$L$이 작아질수록 회전 저항 $M_{scrub}$는 선형적으로 0에 수렴**합니다.
2. **전진/후진 구동 트랙션 ($F_{drive}$)**:
   $$F_{drive} = \mu_x \cdot (mg)$$
   * 전후진 마찰력은 $L$과 무관하며, **총 중량($mg$)과 타이어 고무 마찰계수($\mu_x$)에 의해서만 결정**됩니다.
   * 따라서 **$L$을 줄여도 전후진 가속력, 등판력, 제동력은 100% 온전히 유지**됩니다.
3. **스키드-스티어 황금 종횡비 ($L/W < 0.7$)**:
   * 현재 1호기: $W = 0.17\text{m}$, $L \approx 0.15\text{m}$ ($L/W \approx 0.88$, 거의 정사각형) $\to$ 회전 저항이 극대화된 상태.
   * **개선 목표**: $L$을 **$0.08 \sim 0.10\text{m}$ (8~10cm)**로 축소 ($L/W \approx 0.5 \sim 0.58$ 달성).
   * **기대 효과**: 회전 저항 토크 **40~50% 즉시 감소**, 저속 회전 스톨 해소, 실효 윤거 오차 대폭 감소.

#### ⚖️ 기구 설계 시 피칭(Pitching) 전복 안정성 검증
* 스마트 쓰레기통은 높이가 있는 수직 구조물이므로, 급제동 시 앞뒤 전복 방지를 위한 최소 축간거리를 검증해야 합니다:
  $$\theta_{tip} = \arctan\left(\frac{L/2}{h_{CoG}}\right)$$
* 무게중심 높이 $h_{CoG} \approx 0.25\text{m}$, 최대 감속도 $a_{max} = 0.5\text{ m/s}^2$ 기준:
* **$L \ge 0.08\text{m}$ (8cm 이상)만 확보되면 급제동 시에도 전복이나 앞뒤 출렁임(Pitching) 위험이 전무**함을 확인했습니다. (2호기 섀시 표준으로 강력 권장)

### 3.1 [제어 1] 7단계 S-Curve / 가감속 램프 필터 (Slew-Rate Limiter)
급격한 토크 스파이크에 의한 슬립을 방지하기 위해 `diff_drive_node.py`의 제어 루프(50Hz)에 가감속 램프를 삽입합니다.

$$\begin{aligned}
|a_x| &\le a_{max} = 0.4 \sim 0.5 \text{ m/s}^2 \\
|\alpha_z| &\le \alpha_{max} = 1.2 \sim 1.5 \text{ rad/s}^2
\end{aligned}$$

```python
# diff_drive_node.py 제어 루프 내부 램프 로직
dv = target_v - self._current_v
max_dv = self._max_accel * dt
self._current_v += math.copysign(min(abs(dv), max_dv), dv)

dw = target_w - self._current_w
max_dw = self._max_ang_accel * dt
self._current_w += math.copysign(min(abs(dw), max_dw), dw)
```

### 3.2 [제어 2] IMU 가속도계 기반 실시간 슬립 감지 (Slip Detection & Adaptive Covariance)
* **슬립 판정식**:
  - 휠 엔코더로 계산한 차체 선가속도 $\dot{v}_{enc} = \frac{v_{enc}(t) - v_{enc}(t-dt)}{dt}$
  - IMU 가속도계로 실측한 전진 가속도 $a_{imu,x}$
  - 슬립 비율:
    $$S_{slip} = \frac{|\dot{v}_{enc} - a_{imu,x}|}{\max(|\dot{v}_{enc}|, |a_{imu,x}|, 0.1)}$$
* **적응형 공분산 적용**:
  - $S_{slip} > 0.3$ (슬립 발생) 감지 시: EKF에 전달하는 휠 오도메트리 공분산 $\sigma_x^2, \sigma_y^2$를 즉시 **10~100배로 팽창**시켜, EKF가 미끄러지는 휠 데이터를 무시하고 IMU 자이로와 SLAM LiDAR 스캔 매칭에 100% 의존하도록 유도. *(Moore & Stouch, Springer 2014; Ojeda et al., SPIE 2006)*

### 3.3 [제어 3] 곡선 회전(Arc Turning) 우선 궤적 생성
* 제자리 회전($v=0, \omega \ne 0$)은 횡마찰이 극대화되는 최악의 조건입니다.
* 전진 속도가 미세하게라도 있는 곡선 회전($v \ge 0.05 \text{ m/s}$) 시 타이어 횡슬립 에너지는 제자리 회전 대비 **70% 이상 감소**합니다.
* **Nav2 설정**: `nav2_params.yaml`의 DWB Local Planner에서 `RotateToGoal` 단독 회전 비중을 줄이고 `PathAlign` 곡선 주행 가중치를 높임.

## 4. 🧭 정지형(ZUPT) 3D 지자기 센서 융합 아키텍처 (Stationary Magnetometer Heading Reset)

사용자께서 결정하신 **"정지 상태에서 지자기 센서로 위치/헤딩을 주기적으로 보정"**하는 기법은 학술적으로 **ZUPT (Zero-Velocity Update) 보정 기법**으로 완벽히 정립되어 있습니다. *(Foxlin, IEEE CG&A 2005; Roetenberg et al., IEEE TNSRE 2005)*

```
       [ 주행 중 (v > 0 or w > 0) ]                   [ 정지 판정 (v = 0, w = 0) ]
  ┌─────────────────────────────────────┐         ┌─────────────────────────────────────┐
  │  모터 대전류 흐름 (자기장 왜곡 극심)   │         │  모터 전류 0A (자기장 왜곡 소멸)     │
  │  ▶ 지자기 센서 비활성화               │         │  ▶ 150ms 대기 (역기전력 소멸)       │
  │  ▶ IMU 자이로 + 휠 엔코더 + EKF     │         │  ▶ 3D 틸트 보정 지자기 샘플링       │
  │     적분으로 자세 추정               │         │  ▶ 절대 방위각(Yaw)으로 EKF 리셋    │
  └─────────────────────────────────────┘         └─────────────────────────────────────┘
```

### 4.1 지자기 센서의 3가지 왜곡과 정지 보정 메커니즘
1. **하드 아이언 (Hard-Iron, $\mathbf{b}_{hard}$)**:
   - 로봇 차체 프레임, 배터리 케이스, 모터 내부 영구자석에 의한 **고정 오프셋 자기장**.
   - 로봇을 제자리 360도 회전시켜 원(Circle) 또는 타원체(Ellipsoid)의 중심 오프셋 $(B_{x0}, B_{y0}, B_{z0})$을 구해 사전에 캘리브레이션. *(Gebre-Egziabher et al., ASCE 2006)*
2. **소프트 아이언 (Soft-Iron, $\mathbf{M}_{soft}$)**:
   - 주변 강자성체로 인해 구(Sphere)가 타원체로 일그러지는 현상. $3 \times 3$ 보정 행렬로 복원.
3. **모터 구동 전류 유도 자기장 ($\Delta \mathbf{B}_{motor} \propto I$)**:
   - 주행 중에는 수 A의 전류가 흘러 나침반이 완전히 교란됨.
   - **해결책**: **모터 정지(`PWM=0`, $I=0$) 상태에서만 지자기를 읽음으로써 원천 차단.**

---

### 4.2 3D 틸트 보정 (Tilt-Compensated Heading) 수식
로봇이 바닥 요철 등으로 기울어져 있을 때 Z축 성분이 방위각에 간섭하는 현상을 가속도계로 보정합니다.

1. **가속도계로 Roll($\phi$), Pitch($\theta$) 계산**:
   $$\phi = \text{atan2}(a_y, a_z), \quad \theta = \text{atan2}(-a_x, \sqrt{a_y^2 + a_z^2})$$
2. **지자기 벡터의 수평면 투영 ($B_{xh}, B_{yh}$)**:
   $$B_{xh} = B_x \cos\theta + B_y \sin\phi \sin\theta + B_z \cos\phi \sin\theta$$
   $$B_{yh} = B_y \cos\phi - B_z \sin\phi$$
3. **절대 방위각(Yaw, $\psi_{mag}$) 산출**:
   $$\psi_{mag} = \text{atan2}(-B_{yh}, B_{xh})$$

### 8.2 ✅ 핵심 주장 독립 검증 — $M_{scrub} \propto L$

리포트가 37번 식(일반형)과 81번 식(L만 사용)을 함께 제시해 모순처럼 보이지만,
**바퀴에 대해서는 81번이 옳다.** 직접 유도로 확인함:

제자리 회전(각속도 ω) 시 위치 $(x_i, y_i)$ 바퀴의 접촉점 속도는 $v = \omega(-y_i,\ x_i)$.
- **구름방향(종방향) 성분** $= \omega x_i$ → 바퀴가 **굴러서** 흡수, 저항 작음
- **횡방향 성분** $= -\omega y_i$ → **긁힘**, 저항 큼

횡마찰력 $\mu_y F_N$이 위치 $y_i$에서 만드는 모멘트 $= \mu_y F_N |y_i|$이므로
$$M_{scrub} = \sum_i \mu_y F_{N,i} |y_i| = \mu_y \cdot mg \cdot \frac{L}{2}$$

**윤거 W는 회전저항에 기여하지 않는다.** 그 방향 성분은 바퀴가 굴러서 처리하기 때문.
37번 식은 무지향 패드(썰매)에나 맞는 형태다.

→ **이건 실질적 통찰이다.** "축간거리만 줄이면 직진 접지력을 전혀 잃지 않고 회전저항만
   준다"는 결론이 수학적으로 성립한다. 2호기 섀시 설계에 반영할 가치가 충분하다.

### 8.3 ⚠️ 미검증 전제 — 축간거리 L 값

리포트는 $L \approx 0.15\text{m}$를 전제로 모든 정량 결론(L/W=0.88, 40~50% 감소,
$L \ge 0.08$ 전복 안전)을 도출했다. 그런데 **저장소 어디에도 축간거리 실측 기록이 없다.**
`CLAUDE.md`에 있는 건 윤거(트레드) 0.17m뿐이다.

- L이 실제로 0.15m가 아니면 위 수치가 전부 달라진다.
- 전복 검증에 쓰인 무게중심 높이 $h_{CoG} \approx 0.25\text{m}$도 미검증 추정치다.
- **조치: 2호기 설계 착수 전 L과 $h_{CoG}$를 실측해서 기록할 것.** (Unkle Karrot)

### 8.4 ❌ 정량 과대 — 전륜 테이핑 65%

전륜 2개만 μ를 낮췄을 때 저감률은 다음과 같다(8.2 유도식 기준):
$$\frac{M_{scrub}'}{M_{scrub}} = \frac{\mu_{tape} + \mu_{rubber}}{2\mu_{rubber}}$$

| 테이프 | μ | 실제 저감률 | 리포트 주장 |
|---|---|---|---|
| 종이 마스킹 | 0.35 | **29%** | 65% |
| 캡톤 | 0.20 | **38%** | 65% |
| PTFE | 0.10 | **44%** | 65% |

65%를 내려면 4바퀴 전부 처리해야 하는데, 리포트는 그걸 명시적으로 금지한다(121행).
**즉 자기 규칙 안에서는 달성 불가능한 수치다.**

또한 6번 주장("직진 영향 없음")도 부정확하다. 테이프는 종방향 μ도 함께 낮추므로:
- **가속 시**: 하중이 후륜(순정 고무)으로 이동해 영향이 완화됨 — 비교적 괜찮음
- **제동 시**: 하중이 **전륜(테이핑)으로 이동** → 제동 슬립 악화
- 제동 슬립은 우리가 이미 겪은 **"정지 시 관성 편향"과 코스트맵 유령 장애물의 원인**이다.
  회전을 얻자고 오늘 고친 문제를 되살릴 수 있다.

→ 테이핑은 **되돌리기 쉬운 실험**으로서는 가치가 있으나, 회전 지표만 보고 채택하면 안 되고
   **제동 슬립을 반드시 함께 측정**해야 한다.

### 8.5 ⚠️ 오늘 작업과의 충돌 — 가감속 값

리포트 권고(0.5 m/s², 1.5 rad/s²)는 **오늘 오전까지 쓰던 값**이다. 슬립이 오도메트리를
오염시켜 코스트맵에 유령 장애물을 쌓는 문제를 확인하고 **0.3 / 1.0으로 낮췄다.**
리포트대로 되돌리면 그 작업이 무효가 된다.

또한 `diff_drive_node`에 램프를 추가하는 것은 **자율주행 중에는 이중 제한**이 된다 —
Nav2 DWB가 이미 `acc_lim_x`/`acc_lim_theta`로 가감속을 제한한 속도만 내보내기 때문.
- **다만 수동 조종(대시보드) 경로에는 램프가 전혀 없다.** 거기엔 실익이 있다.
- → **조건부 채택**: 노드 램프는 넣되 기본값을 Nav2와 같은 0.3 / 1.0으로 두고,
  Nav2 값을 되돌리는 건 채택하지 않음.

### 8.6 전제 하나가 이미 바뀌었다 — 회전 문제는 상당 부분 해결됨

리포트는 "저속 회전 스톨"을 현재진행형 문제로 다루지만, **오늘 오전에 원인을 찾아 고쳤다**:
회전 명령을 직진용 속도→PWM 모델에 통과시키던 구조를 분리하고 실측 보정
(`min_turn_pwm=260`, `max_turn_pwm=570`). 검증 결과 명령 0.5→93%, 0.8→102%.

→ 따라서 **하드웨어 개조는 "필수 해결책"이 아니라 "최적화"**로 위치가 바뀌었다.
   급하게 기구를 뜯을 이유가 없고, 폐루프 검증 후 이득을 보고 판단하는 게 맞다.

### 8.7 ZUPT 지자기 — 방향 동의, 다만 선결 조건이 있다

접근 자체는 사용자가 먼저 제안한 것과 같고 오늘 실측과도 부합한다
(정지 시 노이즈 0.8µT로 안정 / 모터 구동 중 52~69µT 요동 → 주행 중 사용 불가).

다만 리포트가 다루지 않은 두 가지가 있다:
1. **하드아이언 보정이 선결**이다. 실측 총 자기장 105~123µT는 지구 자기장(25~65µT)의
   2~5배로, 로봇 자석의 고정 편향이 지배적이다. 보정 없이 방위각을 쓰면 무의미하다.
2. **환경 왜곡은 위치마다 다르다.** 임의 지점에서 헤딩을 리셋하면(리포트 4.3의 5단계)
   냉장고 옆 같은 곳에서 오히려 큰 오차를 주입할 수 있다.
   → **도크처럼 고정된 지점의 자기 서명을 따로 보정해 그 지점에서만 리셋**하는 쪽이
     훨씬 안전하다. 도크는 재현성이 보장되고, 세션 간 맵 복원이라는 실제 용도와도 맞는다.

| L·$h_{CoG}$ 실측 기록 | ✅ **선행 필수** | 모든 정량 결론의 전제가 미검증 |
| 전륜 테이핑 실험 | ⚠️ **조건부 — 실험만** | 되돌리기 쉬움. **단 제동 슬립을 함께 측정**, 회전 지표 단독 판단 금지 |
| 옴니휠 배제 | ✅ **동의** | 마루 손상·소음 근거 타당 |
| 캐스터 2WD 전환 | 🔵 **보류** | 긁힘은 원천 제거되나 모터 2개 유휴·험지 주파력 손실. 2호기 대안으로만 |
| 노드 가감속 램프 | ⚠️ **조건부 채택** | 수동 조종 경로에만 실익. 기본값은 Nav2와 동일(0.3/1.0) |
| Nav2 가감속 0.5/1.5로 복원 | ❌ **기각** | 오늘 슬립 억제 목적으로 낮춘 값. 되돌리면 역행 |
| 슬립 감지 적응형 공분산 | ✅ **채택(우선순위 중)** | EKF가 미끄러지는 휠을 불신하게 만드는 건 유령 장애물 문제의 정공법 |
| 곡선 회전 우선 | 🔵 **보류** | 타당하나 프론티어 탐색에서는 제자리 회전이 불가피한 경우가 많음 |
| ZUPT 지자기 | ✅ **채택하되 범위 축소** | 하드아이언 보정 선행 + **도크 등 고정지점 한정** |

### 8.9 실험 설계 보완 — 회전만 보면 안 된다

리포트 7절 실험계획은 회전 지표(회전각 비율, `min_turn_pwm`)만 본다.
**직진을 망치지 않았는지 반드시 함께 재야 한다.** 각 개선안마다 아래 4개를 세트로 측정:

| 지표 | 측정법 | 좋은 방향 |
|---|---|---|
| 실효 트레드 배수 | `calibrate_drive.py rotate` (현재 1.94) | 1.0에 가까울수록 |
| 회전 시작 PWM 문턱 | PWM 스윕 (현재 약 230) | 낮을수록 |
| **제동 슬립** | 정지 명령 후 추가 이동거리 | **악화되면 안 됨 (핵심)** |
| 직진 트림 변화 | `calibrate_drive.py straight` (현재 0.6) | 크게 안 변해야 |

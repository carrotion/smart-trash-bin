## P0 — 안전 (실운용 위험)

### 1. 속도 제한이 실제로 안 먹힌다 — 데드존 바닥 때문에 저속 명령이 전부 같은 속도
- **발견(2026-09-24)**: `_speed_to_pwm`은 `속도/1.5 × 1200`으로 PWM을 계산하고, 120 미만이면 120으로 끌어올린다. 그래서 **0.04, 0.08, 0.15 m/s 명령이 전부 PWM 120으로 똑같다.** Nav2 `max_vel_x`를 0.3→0.15→0.08→0.04로 네 번 낮췄지만 0.15 아래로는 실제 속도가 한 번도 안 바뀌었다
- 오늘 바닥에서 PWM 160(명령 0.2)은 실제 약 0.57m/s. PWM 120이 바닥에서 몇 m/s인지는 **미측정**
- **8/29 충돌과의 연결(가설)**: DWB는 `sim_time 1.5초 × 0.04m/s = 6cm` 앞만 보고 궤적을 고르는데 로봇은 그 사이 수십 cm를 간다 → 장애물을 "아직 멀다"고 판단. 근접 사각지대(9/4 수정)와 겹쳐 정면충돌을 설명할 수 있다
- **다음**: 바닥에서 PWM 100~250 저속 구간 실제 속도 측정(데드존 포함) → 명령 속도=실제 속도가 되도록 `_speed_to_pwm` 모델 재작성(축별, #6과 함께) → Nav2 속도 한계가 실제로 먹는지 확인
- **완료 기준**: 명령 0.04/0.08/0.15가 서로 다른 실측 속도를 내고 오차 20% 이내

### ~~2. `/cmd_vel` 중재가 없다 (측정 오염 원인)~~ → 오진 정정, 진짜 원인(자이로 바이어스) 수정 (09-24)
- 점검 결과: 대시보드는 **버튼을 누를 때만** 발행(대기 중 15초간 0개 실측). 9/24 "방향 역전·-51°"는 USB-C 재연결 순간 노드가 떠서 손 움직임이 **자이로 바이어스 -0.438 rad/s**로 박힌 탓. 경위는 CLAUDE.md 09-24 절
- 수정: 노드가 바이어스 창의 평균·표준편차로 정지 여부를 판정해 거부·재측정. `hw_preflight.py`가 바이어스 값 검사. 오프라인 시험(사고값 거부/정지 채택/흔들림 거부/구동 중 창 비움) 통과, 재기동 후 -0.0039 rad/s로 정상 채택 확인
- 남은 것 → P2 #12a(수동·자율 명령 중재)

### 2a. 자이로 바이어스 거부 로직의 실물 확인

## P1 — 뒷바퀴 520 교체 후속 (절차 1장 미완 항목)

### 4. 제자리 회전 재캘리브레이션
- 새 모터 조합으로 회전을 한 번도 안 해봤다. `turn_kp=140`, `turn_ki=220`, `min_turn_pwm=49`, `max_angular_speed=2.15`는 전부 370 4개 시절 값
- **다음**: `tools/rotation_calibrate.py`(바닥) — 데드존까지 내려가며, 피드포워드 바뀌면 게인 재튜닝

### 5. 앞/뒤 카운트당거리 6% 불일치
- 바닥 직진에서 같은 쪽 앞뒤가 같은 거리를 가야 하는데 M3/M1=0.92, M4/M2=0.96. 뒤 값(2475.6)은 손 10회전 raw, 앞 값(857.2)은 주행 보정값이라 기준이 다르다
- `calibrate_drive.py straight`는 `/odom` 하나로 비율 하나를 내서 어느 축이 틀렸는지 못 가린다
- **다음**: `calibrate_drive.py`에 축별 거리 출력 추가 → 줄자로 실측 대조 → 축별 보정

### 6. 뒷바퀴 PWM 보정의 저속 구간
- affine 보정(`rear_pwm = 1.7692×front + 461.82`)은 PWM 200~800 무부하 실측에서만 유도됐다. 120~200은 외삽
- **다음**: #1과 같은 측정에서 앞/뒤 따로 → 바닥 부하 상태 기준으로 재유도

### 7. 코스팅 재측정 → `precise_move.py`의 `COAST_K`
- 0.53은 370 4개 시절 값. 520이 관성/마찰을 바꿨다
- **다음**: `tools/coast_sweep.py` 여러 속도(바닥) — #1로 속도 모델이 바뀐 뒤에

### 8. `motor_pwm_offset_m1..m4` · `straight_trim`
- 전부 0으로 리셋된 상태. 현재 직진 이탈 ±2°라 **필요 없을 수 있다** — #1·#4 후 직진 재측정해서 판단하고 결정을 기록

### 9. 앞바퀴도 520으로 교체할지
- #1~#8 결과로 판단. 교체하면 절차 1장을 다시 처음부터

- 30~50cm(빔 간격 1cm 미만)에 원통 다리를 두고 돌려가며 `tools/thin_object_detection_test.py`. 거기서도 누락되면 반사 문제가 실재

- 이미 설치돼 있음(1.3.12). 정지 폴리곤은 Davi 제안(8cm)이 아니라 **차체 앞끝 11cm + 실제 정지거리**로 계산 — #1로 실제 속도가 확정된 뒤

### 12a. 수동 조종 ↔ 자율주행 명령 중재
- 지금은 `motor_dashboard.autonomous_active()`가 Nav2가 떠 있으면 대시보드 주행 명령을 막는 방식(정지는 통과). `map_dashboard`는 비상정지 때만 발행
- 표준 방식은 `twist_mux`(우선순위+타임아웃). 사람이 자율주행 중 개입할 수 있어야 하는지(현재는 못 함)부터 결정 필요 — 자율탐색 재시도(#16) 전에

### 14. 자이로 바이어스 랜덤워크

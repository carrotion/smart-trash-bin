# 로봇 사진 보관

**왜 필요한가**: Claude는 세션이 바뀌면 대화 내용을 기억하지 못하고 저장소만 본다.
사진이 대화에만 있으면 다음 세션에서 사라진다. 배선·장착 상태를 눈으로 확인해야
하는 진단(케이블 간섭, 부품 위치, 차폐 원인)에서 특히 아쉽다.

## 파일 이름 규칙

    YYYYMMDD_각도_설명.jpg

    예) 20260820_side_dock.jpg
        20260820_top_wiring.jpg
        20260820_front.jpg

## 찍어두면 좋은 각도

| 각도 | 왜 |
|---|---|
| **측면** | 데크 높이, 라이다 장착 높이, 도크에 뜬 상태 확인 |
| **위에서** | 부품 배치, 케이블 경로, 라이다 주변 장애물 |
| **정면 / 후면** | 좌우 대칭, 바퀴 정렬(눈대중) |
| **문제 부위 근접** | 커넥터, 드래그가 의심되는 바퀴 주변 |

⚠️ **배선을 바꾸거나 부품을 옮기면 다시 찍어둘 것.** 특히 커넥터 작업 후.
2026-08-20에 M4 구동 사망과 M3 드래그가 모두 커넥터 작업 직후에 생겼는데,
작업 전후 사진이 있었으면 비교로 바로 찾았을 것이다.
